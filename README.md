# cTrader / OKX 行情回放工作站

`codex/ctrader-only` 是独立的静态实验版。网页通过 WebSocket 连接 cTrader 的模拟或真实环境，支持历史回放、实时只读行情、本机模拟交易、指标、画线和多窗口图表。

第三方许可见 [THIRD_PARTY_NOTICES.txt](public/THIRD_PARTY_NOTICES.txt) 和 [许可文件](public/licenses)。构建时会复制到静态产物。

## 切换行情来源

顶部“行情来源”可在 cTrader 和 OKX 之间切换。OKX 通过公开接口读取可交易的 USDT 线性永续合约目录、历史成交价 K 线和实时 K 线，无需 OKX API 密钥。可用周期沿用图表周期列表，2m、4m、10m 由 OKX 较小的 K 线合成，日、周、月使用 UTC K 线。OKX 回放步进从 1 分钟起。两套行情各自记住上次选择的品种，切换时恢复该来源的活动回放会话与模拟账户。

OKX 模拟使用 USDT 逐仓双向持仓。市价单可按张数或保证金下单，合约面值、最小数量、数量／价格步长、市价单上限和持仓档位来自 OKX 公开接口。默认 10× 杠杆受品种上限约束，模拟市价吃单和强平费用按公开 Lv.1 吃单费率 0.05% 计，滑点可调。强平触发优先使用同周期 OKX 标记价格，成交价和区间内的成交顺序仍按 K 线估算。可查询的历史资金费按结算标记价计入逐仓保证金与账户流水。资金费率公开历史约三个月，缺少数据时界面提示。 [OKX API](https://www.okx.com/docs-v5/zh/) [OKX 合约手续费](https://www.okx.com/help/how-to-calculate-the-contract-transaction-fee) [OKX 资金费规则](https://www.okx.com/help/perps-funding-fee-mechanism)

行情来源和各自的当前品种随应用配置／完整 JSON 和 GitHub 应用配置恢复。OKX 的规格快照、会话、持仓、成交和资金费流水随会话／完整 JSON 和 GitHub“会话与交易”保存。旧存档缺少新增配置时保留本机设置，本机无设置时用 cTrader。手动恢复后按提示刷新。

## 行情连接配置

静态网页从同一站点读取连接配置。填入 `clientId`、`clientSecret` 和具有 `SCOPE_VIEW` 权限的 `accessToken` 即可读取授权账户列表。首次连接时，如果有多个授权账户，请选择模拟或真实账户并点击“连接账户”。刷新页面和断线重连会沿用账户选择，只剩一个授权账户时自动连接，已记住的账户不在多个授权账户列表中时会重新询问。需要换账户时，选择“工具 → 切换账户”，确认后工作站重新载入并连接所选账户。旧连接文件的 `accountId` 仍可读取。账户选择仅保存环境和账户 ID，参与 JSON 与 GitHub 应用配置存档，连接时仍以实际授权列表为准。 [静态连接配置](public/ctrader-connection.json)

静态连接文件随网页发布，访问者可以读取它。Token 的只读权限覆盖其授权列表中的全部账户。

如果行情状态提示所选账户无法连接（`CANT_ROUTE_REQUEST`），可在该面板手动切换到其他授权账户。只有一个授权账户时，可稍后刷新页面重试。

正式站直接使用仓库里的 `public/ctrader-connection.json`。更新凭据时，编辑这个文件并推送到 `main`，GitHub Pages 会自动发布。本文件仅填写应用 ID、应用密钥、只读 Access Token 和可选的账户 ID。旧值会保留在 Git 历史中，轮换 Token 后请在 cTrader 撤销旧 Token。当此文件缺失或无效时，本地开发可从仓库根目录的 `ctrader-connection.local.json` 读取配置。

填入新的凭据后，先运行 `npm run dev` 并打开本地页面，确认账户通过认证，再构建静态产物。分别搜索 `EURUSD`、`XAUUSD`、`US500`、`BTCUSD`、`ETHUSD`，核对 IC 品种代码、至少两个原生周期和开市时的实时报价。账户存在不同品种代码时，使用账户列表返回的代码。令牌到期后重复此流程。API 消息和限制见 [cTrader Open API](https://help.ctrader.com/open-api/)。市场行情只在运行中的页面内缓存。

## 手机和平板访问

桌面以图表为主体。回放开始后，右侧显示模拟下单，底部通过“持仓／成交记录／复盘统计／账户流水”标签切换。账户详情、仓位详情、止盈止损、减仓和平仓按需打开。账户摘要、下单和持仓与复盘可通过标题箭头展开／收起；收起后原位保留展开条，右侧下单区保留展开窄轨。顶部“工作区”也可统一切换这些状态或恢复默认布局；“专注看图”临时收起这些附加面板，退出后恢复原布局。回放控制和底部状态在双端常驻，取消显隐入口；状态栏固定在屏幕底部，手机回放控制固定在底部菜单上方，图表滚动时仍可操作。

手机（宽度小于768px，或宽度小于1024px且高度不超过520px的横屏）使用固定底部导航。实时行情可打开行情状态，进入回放后可打开下单及持仓抽屉。再次点击当前底栏“下单”或“持仓”按钮即可收起，点击“看图”、遮罩、标题箭头或按Escape也可收起抽屉；编辑弹窗有独立关闭入口、焦点循环和返回。纵横屏切换沿用同一个图表与下单草稿。手机顶部显示工作站标题与“工具”，点击“工具”展开数据管理、图表尺寸、工作区和专注看图，再点收起；同步正常时不额外占一行，异常／冲突仍显示。手机价格轴透明覆盖在图内最右侧，价格右对齐。图表手动增高后，主图在自动价格模式下可上下滑动浏览图表；手动价格模式下拖动可平移图形并保持缩放比例；最右侧价格轴保留独立纵向缩放区域，横向拖动仍浏览K线。主图价格轴顶部的计价货币标签旁用单个 A 开关切换模式，高亮为自动，关闭为手动；时间轴位于主图与副图的交界处，无副图时仍紧贴主图下方。手机默认收起主图指标信息与绘图侧栏，保留主图价格信息及副图指标信息，可通过产品工具栏右侧箭头随时展开；日期、数字输入和抽屉会根据可见视口避让软键盘。

图表默认填满账户栏与底部控制区之间的可用空间。副图放不下时，可以拖动图表底边，或在“工具 → 图表尺寸”中增高图表。桌面用滚轮、手机在自动价格模式下用上下滑动浏览超出的图表内容，持仓和控制栏固定在底部。桌面与手机分别记住手动高度，各副图的期望高度随指标配置保存。布局及高度偏好支持本地恢复、JSON 备份和 GitHub 应用配置同步，恢复后按界面提示刷新。 [工作区使用说明](docs/workspace-experience.md)

周期下拉框包含 14 个 cTrader 原生周期，列表右侧星标用于固定或取消固定快捷周期；默认固定 5m、15m、1h、4h，选择会保存到当前浏览器，并进入应用配置／全部数据备份及 GitHub“应用配置”同步。快捷栏仅显示固定的周期，手机窄屏时另起一行；固定较多时只在快捷栏内横向拖动，页面不会跟随左右移动。

价格轴支持单指上下拖动缩放和双指捏合缩放，调整后进入手动价格范围。切换图表周期、双击价格轴或点击“A”可恢复自适应。图表内横向滑动浏览历史，双指捏合调整时间尺度；点击或长按图表显示十字光标后，可拖动查看行情。

主图及独立副图可共享手绘图形。点击图形会显示控制栏，可修改描边颜色、线宽和线型，也可锁定、解锁或删除。从锁定图形或锚点开始拖拽时，图表按原有手势平移。单击或轻点图形可选中并解锁，点击主图空白处可收起控制栏。浏览行情时按产品保存，进入回放后按会话保存。在任一周期编辑绘图，查看同一产品或会话的其他窗口会更新。锚点使用时间和价格坐标，在大周期内仍可保留同一根 K 线中的不同时间位置。绘图、样式和单图锁定状态在本机自动保存，支持完整 JSON 和 GitHub 绘图同步。旧绘图缺少锁定状态时默认可拖动，旧备份缺少整个绘图字段时保留现有绘图。数据管理中的“图表绘图存档”可查看总数量及本机、云端大小，确认后可一键清空所有绘图。

移动端回归使用 Chromium 触摸模拟，覆盖 320px、390px、768px、横竖屏切换、回放与模拟下单，以及价格轴拖动、捏合、手势取消和图表区域滚动。实际 iOS Safari 和 Android 浏览器仍需真机验证。

## 图表指标

在图表“设置 → 蜡烛图类型”选择“平均 K 线（Heikin Ashi）”可查看平滑趋势。蜡烛按 HA 公式计算，提示框、指标、最新价和模拟交易仍使用真实行情。首根从已加载历史的开收均值起算，向左加载更多历史后会重新递推。类型选择刷新可恢复，并包含在应用配置／全部数据 JSON 和 GitHub“应用配置”同步中；旧存档缺少类型时保留本地设置，恢复后按提示刷新。

MA、EMA、BOLL、MACD、RSI 等现有指标使用 `klinecharts` 内置实现，指标菜单和参数设置由 `@klinecharts/pro` 提供；行情接入、回放隔离和指标配置保存由本项目实现。

主图十字光标价格标签同时显示相对当前价格的百分比差异：`(指示价格－当前价格)÷当前价格×100%`，带正负号、保留两位小数。实时使用最新真实收盘／成交价格，回放使用当前已揭示行情的价格，不引用未来价格；Heikin Ashi 仍以真实价格为基准。

RSI 默认显示 30（超卖）、50（中线）、70（超买）三条虚线。指标设置可自定义超卖／超买水平，满足 `0 ≤ 超卖 < 50 < 超买 ≤ 100`，也可设置三条线颜色及透明度，原有 RSI 计算周期保持不变。所有现有颜色设置均增加 0–100% 透明度：0% 不透明，100% 完全透明。设置随指标进入本地、配置／完整 JSON 和 GitHub 存档；旧颜色保持原效果，旧 RSI 存档缺少新设置时保留本地对应设置，无本地值才使用默认值。

“指标 → 主图指标 → KC(肯特纳通道)”显示上、中、下三轨。参数依次为 EMA 周期、ATR 倍数、ATR 周期，默认 `20、1.5、20`，倍数支持小数。中轨为收盘价 EMA，上下轨为中轨加减倍数乘 ATR；EMA 用完整窗口 SMA 起始，ATR 首根取 high-low、之后计入相对前收盘价的跳空，以完整窗口 SMA 起始并按 Wilder 平滑。等待两个周期都预热完成才绘制；支持分别修改三轨颜色。

“指标 → 副图指标 → TTM Squeeze(挤压指标)”组合布林带、同一现代肯特纳通道和回归动量：

- 参数依次为共同周期、布林带标准差倍数、KC ATR 倍数，默认 `20、2、1.5`；周期应用于 BB、KC 的 EMA/ATR 和动量计算。
- BB 使用收盘价 SMA 与总体标准差。BB 上轨严格低于 KC 上轨且下轨严格高于 KC 下轨时，零轴显示红点（挤压中）；其他情况显示绿点（未挤压）。红转绿表示挤压解除，持续绿点不代表新的释放信号。通道预热完成才显示圆点。
- 动量基础值为 `close - ((窗口最高价 + 窗口最低价) / 2 + SMA(close)) / 2`，再对同周期基础值做线性回归，取拟合线末端值。默认第 39 根 K 线才开始显示动量柱；此前悬浮值为 `--`。
- 正柱升高／回落分别为青／蓝色，负柱远离／靠近零轴分别为红／黄色；正柱持平按青色、负柱持平按黄色显示。设置窗口可分别修改四色柱和两种状态点的颜色，悬浮提示显示动量和挤压状态。

TTM 的挤压与回归动量思路参考 [StockCharts 指标说明](https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-indicators/ttm-squeeze)，本项目明确采用上述现代 KC 公式；使用原始肯特纳公式、不同 EMA/ATR 起始或平滑方式的平台可能出现不同信号，不承诺跨平台逐点一致。挤压本身不判断方向，动量减弱不等于趋势反转，也不保证释放后会持续突破。

KC 和 TTM 均为自定义指标，不增加依赖、不自动加入默认组合。实时与回放计算仅使用当前及之前提供的 K 线；未完成实时 K 线会更新。选择、参数、可见性、颜色样式和副图高度都沿用现有本地保存、应用配置／全部数据 JSON 导出导入和 GitHub“应用配置”上传恢复。旧存档不自动新增指标，缺少指标配置时保留本地值，显式空列表表示清空；新指标非法参数会在恢复写入前拒绝。导入或云端恢复后按界面提示刷新生效。

“指标 → 副图指标”提供三个独立的 **TTM Wave A（短期波）／B（中期波）／C（长期波）**，可分别勾选、移除、隐藏和调整副图高度。参数依次为快线、慢线一、慢线二周期，默认 A 为 `8、34、55`，B 为 `8、89、144`，C 为 `8、233、377`；必须是正整数且依次递增。设置窗口可修改周期和两组波形颜色，各指标互不影响。

采用 [UDAY_C_Santhakumar 公开 ABC 版本](https://www.tradingview.com/script/nYOzTA1Y-UCS-TTM-Wave-A-B-C/) 的数学口径独立实现：设 `D(p) = EMA(close, 快线) - EMA(close, p)`，`H(p) = D(p) - EMA(D(p), p)`。A/B 的波形一为 `H(慢线二)`、波形二为 `H(慢线一)`；C 的波形一为未经信号平滑相减的 `D(慢线二)`、波形二为 `H(慢线一)`。两组柱状波叠加并显示零轴：每组按自身数值正负着色，上方默认深／浅绿色，下方默认红／橙红色，零值沿用上方颜色。设置窗口可分别调整“波形一／二零线上方／下方颜色”。旧存档的单色保留为上方颜色，下方使用新的默认色；新颜色完整参与本地、JSON 和 GitHub 配置存档。短中长期均指当前图表周期的 EMA 长度，不额外读取更高周期。

Wave 的 EMA 从首根收盘价起算，信号 EMA 从首个差值起算，首根值为 0；只用当前及此前 K 线。尤其 B/C 会受加载历史长度和初始化方式影响；该公开 ABC 版本不承诺与 thinkorswim 闭源 A/C 合并版本逐点一致。三个指标的选择、参数、可见性、颜色和副图高度均进入现有本地、JSON 配置／完整存档和 GitHub“应用配置”往返；旧存档不自动添加指标，恢复后刷新生效。

ABC 之间只保留轻微色调差异，主要以绿色系／红色系区分零线上下。每个副图的波形一使用较深的宽柱，波形二使用较浅的半宽柱，避免 C 波两组数值接近时完全遮挡。读取本地配置或恢复旧存档时，已发布的旧默认色自动升级到当前配色，其他自定义颜色保留；迁移参与现有 JSON、完整存档和 GitHub 配置流程，不新增设置字段。

在“指标 → 主图指标”勾选 `Supertrend(超级趋势)`，可与 MA 等指标叠加。点击图表指标标题旁的设置图标，可修改 ATR 周期和倍数，默认分别为 10 和 3，倍数支持小数；选中状态和参数随现有指标配置保存、备份及恢复。

Supertrend 是本项目通过 KLineCharts 自定义指标接口实现的扩展，不增加额外依赖。计算采用 [TradingView 公开标准公式](https://www.tradingview.com/support/solutions/43000634738-supertrend/)：以最高价和最低价的中点构建 ATR 轨道，ATR 使用 Wilder 平滑（首个周期简单平均，再递推），收盘价穿越轨道后切换方向。上涨为绿线，下跌为红线，方向切换处断开；不足一个 ATR 周期时不显示数值。回放计算仅使用当前及之前已提供的 K 线，未完成的实时 K 线会随价格更新。历史加载范围、ATR 算法或初始值不同都可能造成差异。

“指标 → 主图指标 → Pivots(标准枢轴点)”提供所附 Pine v6 `Pivot points standard` 的移植版本：

- 支持 Traditional、Fibonacci、Woodie、Classic、DM、Camarilla 六种公式，默认 Traditional；
- 枢轴周期支持自动、日、周、月、季度、年及 2/3/5/10 年；自动规则按所附脚本：15 分钟及以下用日，其他日内周期用周，日线用月，周线/月线用年；
- 默认保留 15 组历史，支持 1–200 组，并遵守最多 500 条水平线的显示上限；
- 支持标签、价格、左右位置、线宽，以及 P、R1–R5、S1–S5 各级线的独立显示开关；颜色简化为 P、R、S 三组，同组共用颜色，当前公式不支持的级别会禁用；
- 勾选“当前周期显示上期线”后，将紧邻上一枢轴周期当时的水平线叠加到当前周期，以虚线和“上期”标签区分；上期 P、R、S 也可单独设色，默认关闭。仅当前一段叠加，不在所有历史周期重复延伸；上期线同样遵守各级显示开关，计入 500 条绘线限制；
- 使用上一完整枢轴周期的 OHLC；Woodie 还使用当前周期的开盘价。各周期水平线独立绘制，日历边界按 UTC 计算，显示时区不改变计算边界；
- 默认“使用日线基准数据”从同一行情源读取日/周/月 K 线，季度和多年周期由月 K 线聚合；关闭时仅聚合已加载的图表 K 线，不完整或有缺口的前一周期不会生成水平线；
- 当前周期最后一根 K 线确认完成后，可预先绘制下一组水平线；Woodie 等待下一周期开盘，避免使用未知的开盘价；
- 状态及全部参数随现有指标配置保存、备份和恢复。

上期线是“上一枢轴周期当时显示的线”，例如周枢轴在本周叠加上周那组线，而不是把本周计算结果重复绘制；Woodie 的上期线使用上期开盘价。需要再前一个完整周期的数据，日线基准模式会多取一组历史，即使历史组数为 1 也能叠加；关闭日线基准时仅使用图表已加载数据，有缺口时不补画。旧版每线独立颜色迁移为 P、R1、S1 对应的分组颜色；原始默认橙色迁移为当前 P 橙、R 红、S 绿，各级开关保留。旧存档缺少上期线设置时保留目标浏览器已有的开关与上期颜色；没有已有设置时默认关闭。颜色与开关完整参与本地、JSON 配置／完整存档和 GitHub“应用配置”往返，恢复后刷新生效。

高周期读取沿用缓存、回放截止时间和行情请求保护，不切换主图周期；同一来源周期内复用请求，失败后不随每次行情更新反复重试，刷新数据或跳转时重新读取。仍受单次历史读取最多 499 根来源 K 线及已上市历史长度限制。数据不足时，指标标题旁提示所需历史。枢轴点使用 cTrader 原生行情的收盘价，跨平台数值可能因数据源不同而不同。

### 市场开收盘

在“指标 → 主图指标”勾选“市场开收盘”。日内主图按正式开盘至收盘显示东京、伦敦、纽约的连续色块，时间落在图表范围内时画出开盘和收盘线。沿主图原有时间轴向右滚动可看到最新 K 线之后一天的时段，额外生成的时段保留到各自收盘。实时以最新行情位置为参考，历史回放以回放进度为参考。

点击指标旁的设置图标，可以分别勾选“显示东京”“显示伦敦”“显示纽约”。默认显示全部市场。取消勾选后，点击“确定”即可隐藏该市场的底色、开收盘线和休市标签。同时也可以调整各市场的底色和透明度，以及开收盘线的线型和线宽。线条使用对应市场的色相，底色透明度只作用于背景。线宽设为 0 时隐藏开收盘线及其标签。手机上可先点“显示主图指标信息”。

以三个交易所的常规股票交易时段为准。东京标当天首次开盘和最终收盘；伦敦和纽约分别按当地时区切换夏令时。周末及节假日按交易所当地日期保留常规时段色块并注明休市，适用的提前收盘日使用实际收盘时间。内置东京 2026–2027 年和伦敦、纽约 2026–2028 年的节假日与提前收盘安排。其他年份按常规交易时间显示，仍标记当地周末与东京固定的年末年初休市日。交易日历见 [JPX](https://www.jpx.co.jp/english/corporate/about-jpx/calendar/)、[伦敦证交所](https://www.londonstockexchange.com/en/resources/markets-products/business-days)、[纽约证交所](https://www.nyse.com/trade/hours-calendars)。

选中状态、各市场显隐和样式随“应用配置”、完整 JSON 和 GitHub“应用配置”备份与恢复。旧存档会保留底色和正式开收盘线的设置，并移除旧预告设置。旧存档缺少市场开关或样式时优先保留本机设置，本机无市场开关设置时显示全部市场。手动恢复后按界面提示刷新。

## 开始历史回放

1. 点击图表左上角的品种代码搜索、切换或收藏品种，在图表顶部选择周期；
2. 拖动实时图表、点击“上一根／下一根”，或用“时间定位”选定回放起点。时间定位会把目标 K 线放到视口最右侧，最右侧可见的 K 线就是回放起点；
3. 新会话以创建时的时间为结束边界，回放可用的最后一根 K 线须在该边界前完成；
4. 点击“创建回放”会暂停实时订阅、读取起点的已收盘 K 线和 IC Markets 交易规格。回放开始后显示模拟下单与持仓面板。
5. 在“回放设置”可填写初始模拟资金、模拟杠杆和额外滑点。杠杆默认取账户与品种规格决定的倍率。回放进行中可再次打开设置，调整钱包余额、杠杆和滑点，并查看初始资金、回放进度与券商交易规格。
6. 在模拟下单面板按手数或保证金金额开多、开空。最小手数和步长取自当前品种。保证金、佣金和盈亏以账户币种结算。详见 [历史模拟交易](docs/simulation-positions.md)。
7. 在各自的仓位卡片按价格或相对开仓均价的百分比设置止盈和止损，输入时可查看预计盈亏和百分比对应的触发价。也可先点选图表上的仓位或止盈止损标签，看到左侧拖动标识后，拖动整块标签并松手确认。拖动仓位标签时，系统按目标价相对当前价的方向设置止盈或止损。触发时只关闭对应仓位，同向加仓和部分减仓保留已设价格，完全平仓后清除。系统从下一根 K 线开始依次检查强平、止损和止盈；
8. 在回放栏用“步进”下拉框选择每步时长，默认 `1m`。点击“下一根”前进一步，长按按当前速度播放，松开即暂停。也可使用上一根、播放速度、跳转结束和重置控制进度；
9. 到达终点、点击“跳转结束”走完剩余行情或手动“结束会话”后，工作台自动恢复最新行情。刷新可恢复尚未结束的活动会话。已结束会话可从“回放设置”重新打开并查看持仓与交易记录。
10. 要删除会话，先结束当前回放，再打开“回放设置”，选中已有会话，点击“删除会话”并确认。本机会话、模拟账户、持仓、成交和流水会一并删除，删除后的本地导出只包含剩余会话，之前的 JSON 和 GitHub 备份仍可手动恢复。

活动回放会话只向图表和指标提供当前回放时间及以前的 K 线。产生交易后禁止回退。重置会话会清空该会话的模拟账户、持仓和交易记录，并使用会话保存的交易规格。新会话按账户保证金水平执行强平。早期会话继续使用原先保存的规则。

主图回放栏和每个独立副图顶部各有一个「交易标记」开关，分别控制本图的成交标记、持仓均价线和止盈止损线。旧会话也会显示逐仓预估强平线。主图开关随应用配置保存和同步。副图开关仅在当前窗口有效，刷新或重新打开副图时默认显示。各图表按自身周期显示成交标记和回放进度线。任一图表都可以拖动仓位或止盈止损标签调整保护价，松手确认后所有图表立即更新。回放进度线在关闭标记时继续显示。

成交标记显示在对应 K 线上方，引线箭头指向上影线顶端。买入为绿、卖出为红，重叠时按成交时间从上到下排列。图表左侧仓位标签显示当前浮动盈亏，多仓为绿，空仓为红。右侧止盈止损标签按盈亏着色，显示对应触发价扣除预计平仓手续费后的盈亏，拖动时实时更新。开仓均价和触发价显示在价格轴上。

IC Markets 回放可在持仓期间调整模拟杠杆，取值为 1 到品种默认倍率的整数。点击“应用交易参数”后，新的杠杆和滑点用于后续订单预估与模拟交易，已有持仓保留原成交占用的保证金。输入目标钱包余额并点击“设置余额”即可增加或减少模拟资金，差额计入账户流水。会话参数、余额与流水随会话自动保存，并支持会话／全部数据 JSON 和 GitHub“会话与交易”上传恢复。旧会话使用已存参数，手动恢复后按提示刷新。详见 [模拟双向持仓](docs/simulation-positions.md)。

回放栏「步进」可选择逐笔 Tick、`1s`、`5s`、`15s` 和 cTrader 原生 K 线周期，默认 `1m`。逐笔模式按 cTrader 历史买价报价处理，保留同一毫秒内的报价顺序。秒级模式以同一份报价生成固定时间段的开高低收，跳过无报价的时间段。模拟订单按每一步的价格处理。切换到更大的步进周期时，从下一个完整且未处理的区间继续。

步进选择随应用配置保存，当前秒级或逐笔位置随回放会话保存。逐笔和秒级步进共用按 10 分钟读取的报价缓存，回放图表按最多 256 根的时间范围提前读取，并按进度逐根显示。主副图和回放共用原生行情缓存，重叠区间只补缺失部分。缓存留在当前页面内存。

图表按所选周期显示回放行情。在 15 分钟图上按 1 分钟前进，正在形成的 15 分钟 K 线随每一步更新，收盘时由 cTrader 原生 K 线替换。在 1 分钟图上按 15 分钟前进，一步可显示多根已走过的 1 分钟 K 线。逐笔和秒级步进只使用已揭示的报价更新当前 K 线。进度和模拟交易随活动会话保存，刷新后图表按已保存的进度恢复。旧币安会话可以在设置列表及存档中查看、导出，来源和品种代码保留。

桌面端点击“打开副图”可连续新开独立窗口。各窗口独立选周期，跟随主窗口的合约、回放进度和实时行情。详见 [工作区使用说明](docs/workspace-experience.md)。

切周期会恢复当前视口右侧对应的时间位置，切回小周期保留原来的具体时间。“定位最新”在实时模式回到最新行情，在历史会话中只回到当前已揭示的最新 K 线，不推进回放。主图和副图按各自周期显示同一回放进度。详见 [多周期观察与图表定位](docs/chart-navigation.md)。

## 查看实时行情

打开工作台即进入实时行情，尚未结束的活动回放会在刷新后恢复。主图与副图共享同一个 cTrader 连接。进行中的 K 线随实时买价更新，收到官方收盘数据后以其价格和报价量为准。断线后会重新认证、恢复订阅并补读历史。行情状态区提示休市、重连和配置问题。K 线详情中的报价量是报价次数。使用“时间定位”可定位历史区间，“定位最新”回到最新可用行情。实时行情下的“上一根／下一根”按当前图表周期移动一根 K 线。

向左浏览到当前最早的 K 线时，图表会自动请求更早的原生 K 线。遇到没有报价的区间，可继续向左拖动查询更早的区间。查看旧行情时，实时 K 线仍在更新。

## 主图成交量

主工作区使用 IC Markets 的 cTrader K 线、回放游标和模拟成交规则。品种列表标出可用的 [OKX](src/market-data/okx/instruments.json) 和 [Bybit](src/market-data/bybit/instruments.json) 成交量来源。OKX `US500-USDT-SWAP` 和 `US100-USDT-SWAP` 分别覆盖 `US500` 和 `USTEC`，使用指数点位。Bybit 的 ETF 代理按每根 IC K 线开盘价和该根内首笔 Bybit 成交建立比例，只投影 Bybit 的图上成交价。OKX 逐笔张数按合约面值折算成标的数量，再计算 USDT 名义金额。

进页面只通过 WebSocket 接收实时逐笔，优先订阅 OKX `trades-all`。没有 OKX 映射或实时连接失败时订阅 Bybit。历史逐笔由顶部的「下载成交数据」手动加载。同一笔 OKX 成交同时出现在接口和 WebSocket 时，按成交 ID 去重。

点击顶部的「下载成交数据」后选择 UTC 锚点日期，默认取最右侧可见 K 线开盘时间所在日。往前和往后的天数默认各 0 天，只选中锚点当天。超过当前 UTC 日期的部分会跳过。OKX 下载确认弹窗按日期列出「平台未归档」「Git 未缓存」「Git 已缓存」「已加载」，查询出错时提示「检查失败」。可以选择「只下载归档」，或确认使用 OKX 历史逐笔接口补齐近期缺档。当天接口数据取至发起请求时，重新打开弹窗可查看已加载时间。超出接口覆盖范围的日期会在对应行标明。已结束的日期优先复用 Git 中的 OKX 日档，官方已发布的完整日档可交给后台缓存，缺档时可回退 Bybit。OKX 完整日档发布后会清理同品种同日可由它替代的 Bybit 缓存。接口数据保留在当前页面，刷新后通过按钮重新加载。见 [成交缓存约定](docs/cloud-storage.md#okx-逐笔成交缓存)。

确认下载时会记下最右侧可见 K 线。逐笔数据从该 K 线已确认的时间边界往左补，后续区间从该边界往右准备。Git 日档下载并校验压缩分片后按小时交付，OKX 接口逐页更新。回放期间，已准备的后续成交随游标揭示。

「指标」顶部的「订单流」分组提供足迹图、大单气泡、Profile 和累计成交量差（CVD）。每项都有独立设置按钮。逐笔成交缺失时，从工具栏的「下载成交数据」补齐历史。回放中的指标只使用游标之前的成交。

订单流配色使用指标设置里的同一套拾色器。点击色块选色，旁边的百分比调整透明度，0% 为不透明，100% 为完全透明。

- **足迹图（Footprint）** 在每根 K 线旁显示价位成交。「数值内容」和「图形内容」均可选 Bid / Ask、总量、Delta 或 Delta / 总量。例如数值选 Bid / Ask、图形选 Delta、显示样式选横条，同一价位就会显示左侧 Bid、右侧 Ask 和 Delta 横条。横条长度按 Delta 绝对值绘制，颜色区分正负。「图形内容」也可跟随数值内容。数字绘制在图形和绘图上方。开启对角失衡时，符合条件的 Bid 或 Ask 数字使用设定的失衡色。还支持成交笔数、成交额筛选、价位合并、配色、字号和 POC。开启时自动加宽 K 线间距，关闭后恢复开启前的间距。自动分档会按蜡烛的屏幕高度减少分组。价位较密时数字会缩小，空间仍不足时隔档显示。
- **大单气泡（Big Trades）** 的 Volume 按单笔金额筛选。Aggregate 按交易所、毫秒、价格和方向合并，再按合计金额筛选，默认最低额为 25,000 USDT。设置支持最高额、形状、空心、半径、数值和买卖填充与描边。最低或最高额设为 0 时分别取消下限或上限。悬停可查看成交方向、来源、数量、金额及聚合笔数。
- **框选成交分布（Profile）** 从左侧绘图工具栏选择，使用两个点框出时间和价格范围。可在指标列表的齿轮设定展示内容、分档、宽度、配色、POC 和价值区。改动会在当前选区上生效。默认右侧为成交量，左侧为 Delta，POC 标记最大成交量价位，VAH / VAL 标记从 POC 向两侧扩展到 70% 成交量的价值区。选区绘图随当前品种或回放会话保存和同步。
- **累计成交量差（CVD）** 在独立副图累计主动买入量减主动卖出量，支持折线或柱形、UTC 日切或连续累计、零线和配色。日切模式下，跨多日的 K 线只取其最后一个已揭示的 UTC 日。连续模式从已加载的 K 线起算。逐笔覆盖缺口处留空，下一段从零累计。

指标选择和上述设置随本地、配置 JSON／完整 JSON 以及 GitHub「应用配置」保存。旧档缺少订单流设置时保留本机值，首次使用采用默认值。手动导入后按提示刷新。

图表用浅蓝色标出计算中的区间。实时成交增量更新，切换周期或缩放只补算未覆盖区间。历史回放随游标逐步显示成交，归档计算结果保存在浏览器，刷新后手动加载同日时可复用。模式、阈值、样式、选中和显隐状态随本机设置、应用配置／完整 JSON 及 GitHub 应用配置保存。旧存档缺少模式或颜色时沿用本机对应设置，本机无值时使用 Volume 和默认配色。手动恢复后按界面提示刷新。
