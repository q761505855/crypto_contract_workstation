# 多周期观察与图表定位

切换周期时，以当前视口右侧 K 线的时间为锚点加载新周期，并在数据就绪后恢复位置。切到较大周期时定位到包含这个时间的 K 线；没有另行平移时，再切回小周期仍保留原来的具体时间。点击已经选中的周期不重新加载。

图表时间输入框旁的“定位最新”只移动图表，不推进、重置或结束会话，也不改变持仓、成交及交易参数：

- 实时模式定位最新行情，已有的当前实时 K 线保留。
- 历史模拟会话定位当前回放已揭示的最新 K 线，不使用实际当前日期。
- 尚未创建历史会话时，定位当前可取得的最新行情。

## 回放边界

会话每一步揭示完整的一根源周期 K 线。其他图表周期共用它的结束边界，而不是把较大周期缓存的完整行情直接展示出来。例如源周期为 15m、当前源 K 线从 12:00 开始，切到 1m 可查看已揭示的 12:00–12:14；不能查看 12:15 以后。切到日、周、月时，当前未完成的大周期只用已揭示的分钟合成，其价格、成交量和指标输入都不包含边界之后的数据。

提前下载或从 Git 恢复的完整月份可以留在缓存，但不改变上述展示边界。切会话、回退后再前进，以及旧请求晚返回，都按当前会话代际校验，旧结果不会重新选择周期或把未来数据写回图表。

创建会话只预加载起点所在 UTC 月及下个月；进入新月份时再补一个月。恢复时预加载上限为当前回放进度的下个月，较早历史用于恢复回退和重置，不提前准备后续整段。会话原定结束时间及总步数继续保存，缓存用尽不代表会话完成；补数据失败不会推进时间或处理交易，重试后继续。周线等跨月源周期只预取窗口内完整收盘的源 K 线，避免因一根跨月柱多下载后一个月。只有主动“跳转结束”才逐月准备并处理至会话终点。

载入或回退会话时，先隐藏旧行情并重置指标历史，再加载当前边界内的数据，避免加载期间残留旧视图。

## 请求与缓存

切周期、换产品或手动定位会取消旧图表历史请求；静默指标读取保留独立的选择通知语义。取消不会被记成历史数据永久失败，下一次查看相同范围可正常重试。已经提交的缓存保留；取消时正在写入的批次原子回滚，避免大量旧分钟写入阻塞新周期读取。

历史会话复用已经读取的分钟数据，切日、周、月及切回小周期只补读缺失片段或新增揭示的尾段。运行缓存最多保留 100,000 根分钟线，回退或换会话清理；它不参与导出和云端上传。大批缓存写入在同一事务内分段排队，既保留整批原子性，也能及时响应取消。

图库自身的历史初始化及分页结果有独立取消序号，避免晚返回结果覆盖手动定位。该序号不关闭当前有效的实时订阅。按月读取、归档优先、后台云端上传及请求保护继续沿用现有逻辑。

视口锚点、待定位请求和取消状态是本次页面的运行状态，不新增用户配置或持久化键。既有配置的本地保存、JSON 备份和 GitHub 上传／恢复链路保持不变。
