# 图表价格差异、RSI、透明度与自动配置同步

用户已一次确认需求，并要求直接在 main 实施、测试、中文提交和推送，实施中不再提问。

- 主图十字光标价格旁显示相对当前真实价格的有符号百分比，两位小数。回放只以已揭示行情为基准。
- RSI 保留原有计算周期，新增默认 30/50/70 水平线。超卖、超买可配置且满足 0 ≤ 超卖 < 50 < 超买 ≤ 100，50 固定。水平线颜色支持透明度。
- 所有已有颜色设置增加 0–100% 透明度。旧不透明颜色保持原值；显式全透明必须保存和恢复。统一颜色校验覆盖指标样式及 Pivots 参数。
- 配置修改本地保存后合并约一秒自动上传；失败保存本设备待同步状态并重试。启动先检查云端，无未上传修改时恢复云端，有未上传修改时进行三方比较，自动合并互不冲突的配置字段，同字段冲突保留本地并显示状态，不静默覆盖云端。
- 启动恢复先于 App 初始化，避免旧组件反写。运行期间恢复发出配置恢复事件，重建相关界面；不重置活动业务数据。
- 只自动处理应用配置，不上传凭据、设备请求保护、会话或行情。所有写入仅在当前项目命名空间内，使用已有 SHA-256 校验及原子分支提交。
- 本地、配置 JSON、完整 JSON、GitHub 上传与拉取覆盖同一配置。旧存档缺字段保留本地值，空列表、false、0 原样恢复，非法数据在任何写入前拒绝。

## 方案选择

复用图表的指标扩展和现有依赖补丁，避免另建平行图表控件；配置自动同步采用独立服务及本设备基线，不把运行状态加入 BackupPreferences。单纯定时全量覆盖无法保护跨设备修改；每次即时上传会使拖动操作产生大量提交，因此合并短时连续更改。

## 验证

模块测试覆盖百分比边界、RSI 参数、颜色透明度与非法值、旧存档迁移、完整配置往返、启动恢复、离线重试、同步中修改、三方冲突及命名空间。执行 npm run check 与相关 Playwright，检查最终 diff 后提交推送。
