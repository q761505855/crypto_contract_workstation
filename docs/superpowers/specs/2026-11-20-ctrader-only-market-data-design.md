# cTrader 行情实验分支

## 目标

在 `codex/ctrader-only` 上把行情来源切换为 IC Markets 的 cTrader Open API。静态网页直接连接 cTrader，按所选周期读取原生 K 线，并订阅实时报价和 K 线。保留现有图表、历史回放和本地模拟交易。用户可以在手机或电脑打开同一静态网页。

实验分支停止使用币安 REST、WebSocket、官方归档和 GitHub 行情分片。图表按需读取 cTrader，不再下载分钟底库或用分钟线换算其他周期。

## 方案选择

| 方案 | 页面如何连接 | 凭据如何提供 |
| --- | --- | --- |
| 静态网页直连，发布配置（已选定） | 网页直接打开 cTrader WebSocket | 本仓库的实验分支提交连接配置，静态部署时将其发布到网页 |
| 静态网页直连，打开页面后输入 | 同样由网页直连 | 每次打开页面需要提供凭据 |
| 独立行情服务 | 网页经服务请求行情 | 服务持有凭据，需要额外部署 |

采用第一项。页面允许公开访问，访问者也能读取发布配置，这是已确认的行为。连接配置只包含 IC 模拟账户的应用 ID、应用密钥及 Access Token。发布配置前先用官方接口确认 Token 仅授权给指定模拟账户，权限为只读。网页连接时同样核对账户、环境与权限。Access Token 到期后更新发布配置并重新部署。GitHub 存档凭据和 Refresh Token 不加入连接配置。

## 行情协议

- 浏览器共用一条到官方模拟环境的 JSON WebSocket，依次完成应用认证和指定账户认证，按官方要求发送心跳。重连后重新认证和恢复仍在使用的订阅。认证失败、权限不符、行情连接中断和市场休市在页面上分别提示。
- 品种由账户的品种列表和详情接口提供，首轮验收使用 `EURUSD`、`XAUUSD`、`US500`、`BTCUSD`、`ETHUSD`。原生 Tick 数标为报价量，缺失的成交量和成交额不填造。交易时段和节假日按品种信息处理，休市范围不触发重复补数据。
- 只提供 cTrader 原生周期 `1m`、`2m`、`3m`、`4m`、`5m`、`10m`、`15m`、`30m`、`1h`、`4h`、`12h`、`1d`、`1w`、`1M`。历史按时间范围分页拉取，短期缓存限于页面内存。对外时间使用接口返回的 UTC 时间戳，界面继续按现有时间格式显示。
- 当前价格随报价流更新，已收盘 K 线由 cTrader 原生推送或历史接口确认。允许用报价更新实时图上正在形成的同周期 K 线，切换品种和周期时丢弃过期回包。历史请求在单连接内排队，低于官方每秒五次上限。

## 回放与存档

- 回放按选定品种的原生步进周期向前或向后移动，跨休市时直接跳到下一根或上一根可用的原生 K 线，休市期间没有模拟成交。任意图表周期仅显示在回放时钟之前已经收盘的原生 K 线。例如，1 小时图配合 1 分钟步进时，开市期间回放时钟继续按分钟推进，图上在小时收盘后才增加一根完整 K 线。模拟委托以步进周期的原生 OHLC 处理，既有模拟成交规则继续适用。
- 切换到 cTrader 后，旧币安会话和交易记录保留存档兼容。实验分支识别来源并阻止在 cTrader 上继续运行这些会话。旧产品不自动映射为 CFD。
- 当前品种、收藏、固定周期和回放步进继续通过本地、JSON 与 GitHub 应用配置往返。旧存档可校验和导入。币安 REST 地址仅作旧格式兼容，不接入行情运行时。旧存档的不可用周期仍可识别并保留，界面仅提供当前支持的周期。选中周期不可用时，运行时采用原生 `1m`，显式空收藏和空固定周期保持原义。
- 实验分支使用单独的浏览器配置与 IndexedDB 命名空间。云端写入限定在 `projects/crypto-contract-workstation/experiments/ctrader/`，与正常版使用的配置、会话和画线分开。保留配置、画线和会话档案的同步。旧行情分片不拉取、不上传，原仓库已有分片和其他项目文件保留。JSON 和 GitHub 配置、会话及画线存档均不包含连接凭据。

## 发布与验收

- 当前 GitHub Pages 生产部署由 `main` 触发。实验分支先生成独立的静态产物，通过预览验证。若需把实验版发布到现有生产地址，先确认切换。已用现有 Pages 的 Origin 向 cTrader 模拟端点验证 WebSocket 握手，返回 HTTP 101。
- 使用本地可控的 WebSocket 测试替身覆盖认证顺序、支持周期、历史分页、重连订阅和休市回放。用真实 IC 模拟账户验收五个品种的历史与实时路径。
- 运行 `npm run check` 和对应的 Playwright 测试，覆盖静态构建、图表切换、回放不提前显示 K 线、旧存档兼容及配置往返。验证 GitHub 行情写入被关闭，连接配置随实验静态产物发布。
