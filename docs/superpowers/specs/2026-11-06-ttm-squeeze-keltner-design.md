# TTM Squeeze 与肯特纳通道

## 目的与范围

在现有指标选择窗口中增加主图指标 `KC`（肯特纳通道）和副图指标 `TTM_SQUEEZE`。用户可选择、移除、调整参数和样式；实时行情和历史回放共用计算，所有结果仅依赖当前及以前的 K 线。保持现有默认指标组合，不自动添加这两个指标。不增加交易自动执行或指标提醒。

## 实现方式

沿用现有 Supertrend 的自定义指标注册、KLineCharts 渲染和 Pro 设置窗口扩展。现有指标状态已统一保存、导出和同步，因此这是当前项目适合的接入方式。独立新增指标界面会重复配置和存档逻辑；引入另一套图表或计算依赖没有必要。

以下计算与展示细节是实现建议，待用户确认。

## 计算与展示

- `KC`：参数依次为 EMA 周期、ATR 倍数、ATR 周期，默认 `[20, 1.5, 20]`。中轨为收盘价 EMA，上下轨为中轨加减 ATR 倍数。EMA 使用完整窗口 SMA 起始值；ATR 首根真实波幅取 high-low，之后计入跳空，以完整窗口 SMA 起始并按 Wilder RMA 平滑。两者预热完成才输出三条轨道。
- `TTM_SQUEEZE`：参数依次为共同周期、布林带标准差倍数、KC ATR 倍数，默认 `[20, 2, 1.5]`。布林带用收盘价 SMA 和总体标准差；KC 与主图使用同一实现，EMA 与 ATR 均采用共同周期。
- 布林带上轨严格低于 KC 上轨，且下轨严格高于 KC 下轨时，零轴显示红点，表示挤压。其余情况显示绿点，表示未挤压。红转绿表示挤压解除，连续绿点不作为重复释放事件。
- 动量基础值为 `close - ((最高价 + 最低价) / 2 + SMA(close)) / 2`，最高价、最低价和 SMA 都取共同周期。对基础值再做同周期线性回归，取窗口末端拟合值作为动量柱。完整预热前不输出动量；默认需 39 根 K 线。
- 正柱上升为青色、正柱回落为蓝色；负柱下降为红色、负柱回升为黄色。零轴圆点与动量柱使用各自颜色，不把红色挤压点解释为做空信号。提供中文名称、参数标签和悬浮数值。
- 周期必须为正整数，倍数必须为有限正数；非法参数不得进入导入或恢复写入。计算函数对不可计算参数防御性返回空结果，不绘制 NaN 或 Infinity。
- 不承诺与所有同名指标逐点一致：其他平台可能使用原始肯特纳公式、不同 ATR 平滑或回归预热方式；README 明确当前公式。

## 配置与兼容

继续使用 `chart.indicators.v1` 和 `BackupPreferences.chartIndicators`，不增加顶层配置字段或存储键。覆盖指标名称、参数、可见性、样式、副图高度，统一经过现有本地入口、配置导出、完整导出、导入、GitHub 配置序列化与解析。

针对两个新增指标增加参数校验，同时保持既有指标的兼容行为。旧存档没有新增指标时不自动添加；缺少 `chartIndicators` 时保留目标浏览器配置；显式空 main/sub 列表仍表示清空；`visible: false` 和合法样式数值 `0` 原样保留。损坏的本地配置按既有规则回退，非法导入在任何数据写入前拒绝。
