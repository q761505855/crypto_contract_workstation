# 工作区使用说明

## 桌面

图表占据主要空间，右侧用于下单，底部集中管理持仓、成交、复盘统计和账户流水。账户摘要的“详情”查看完整账户。每张仓位卡片明确标示多仓或空仓，“止盈止损”“减仓 / 平仓”“详情”只操作对应方向。多空可以同时存在，同方向加仓合并，保护价随该方向仓位保存；结束该仓位后保护价随之移除。

创建会话前可直接“创建回放”，或先打开“回放设置”调整资金、杠杆、结束时间及高级费用参数；已有会话的重置、结束、跳转结束收在回放设置内。时间跳转使用“时间定位”，不常用表单不再常驻图表周围。

“工作区”管理账户摘要、下单、持仓与复盘三个开关；回放控制和底部状态双端常驻，不提供展开／收起按钮或工作区复选框。各面板标题处使用展开／收起箭头，并通过aria-expanded标明当前状态。收起后正文保留在DOM中，原位留下带名称的展开条；右侧下单区保留32px展开窄轨。可直接反复切换，无需另开设置找回。专注看图时收起这三个面板及其折叠入口，回放控制与状态栏继续显示；退出后恢复原状。“显示全部面板”恢复开关，“恢复默认布局”同时恢复自动图表高度及默认持仓面板高度。“专注看图”是临时模式，退出后回到已有偏好。

## 手机与横屏

宽度小于768px的手机，以及宽度小于1024px且高度不超过520px的横屏，使用固定底部导航。点击“下单”或“持仓”打开抽屉；再次点击当前“下单”或“持仓”底栏按钮即可收起，再点即可展开；点击“看图”、抽屉外遮罩、面板标题箭头或Escape也可返回图表。抽屉与桌面使用同一组件，跨尺寸切换保留下单草稿与图表实例。底部“更多”打开工作区，即使附加面板全部隐藏也能恢复。

手机顶部默认只保留模式切换和“工具”，展开工具后可访问数据管理、图表尺寸、工作区和专注看图；再次点击收起。同步正常时状态条收进工具区，错误和冲突仍可见。手机默认收起主图指标信息与绘图侧栏，保留主图价格信息及副图指标信息，减少文字遮挡K线，产品工具栏右侧的信息箭头和原生绘图入口可随时展开。输入字号至少16px，主要触摸控件约44px；表单弹窗和抽屉跟随可见视口高度，编辑时可滚动。每个编辑弹窗都有关闭按钮；键盘Tab在弹窗内循环，Escape关闭并返回触发入口。高图表允许页面滚动，同时保留顶部和底部导航。

实时模式保留相同图表工作区，右侧或底部“行情状态”查看连接信息，不提供真实交易。

## 调整图表和指标尺寸

顶部“图表尺寸”提供图表区域及现有副图的滑杆。整体高度可设280–1600px；桌面、手机独立保存；选择“自动适配”则填充当前可用空间。图表底边也可拖动，用键盘方向键每次调整20px，Shift配合方向键调整100px，Home/End设置范围端点。桌面底部持仓区域可以拖动边界或在工作区设置160–480px高度。

指标副图期望高度可设60–600px，也可以拖动原生分隔线调整。当前空间放不下全部副图时，显示尺寸按比例压缩，主图至少保留约180px。手机副图合计上限约为屏幕高度22%，拉高整体图表主要增加主图空间，副图不会随之一起放大；回到桌面仍按存档的期望高度显示。压缩是临时显示行为，不进入备份；显式拖动会更新保存的期望高度。

## 配置与兼容

工作区配置统一保存于`workspace.layout.v1`，存档字段为`BackupPreferences.workspace`，包含三个活动面板开关、两个旧显隐兼容字段、桌面/手机图表高度和持仓面板高度。副图高度继续使用现有`chartIndicators`配置。应用配置导出、完整导出、JSON导入及GitHub“应用配置”上传/恢复均包含这些设置。

旧存档没有`workspace`时保留本地布局。账户、下单和持仓的显式`false`会收起正文并保留原位展开入口；旧replay/status的false仅保留为存档兼容值，不再隐藏常驻区域，显式`null`会恢复自动高度，不会被当作字段缺失。非法布局在写入任何数据之前拒绝。恢复配置后按界面提示刷新，避免旧组件状态覆盖刚恢复的配置。

顶部工具展开状态、临时展开的抽屉、编辑弹窗、专注状态以及主图指标信息的展开状态不进入存档。Token、请求冷却和跨页面保护等设备状态不进入布局备份。

## 开发与回归

`npm run check`执行类型检查、单元测试和生产构建。浏览器回归使用模拟行情及GitHub拦截，不发送真实订单或真实云端写入：

```sh
npx playwright test e2e/app-shell.spec.ts e2e/history-storage.spec.ts e2e/workspace-keyboard.spec.ts
```

覆盖隐藏与恢复、桌面／手机独立高度、双仓保护价与减仓、标签和弹窗、触摸、横竖屏、原生指标参数／绘制、JSON与云端往返，以及可见视口因软键盘缩小时的操作可达性。手机使用Chromium触摸模拟；键盘用例保留布局视口，模拟原生visualViewport缩小事件。

`patches/klinecharts+9.8.12.patch`保留现有价格轴与手势修复，并修复同一动画帧内普通绘图抢先排队时，后续尺寸更新回调被丢弃的问题，防止切换面板后底图位图尺寸滞后。`canvas-resize.test.ts`直接验证安装包的调度代码在两种像素观察器路径下应用最新尺寸，且每帧仍只绘制一次。修改依赖补丁后，开发服务器需用`--force`重新优化依赖缓存。

## 原生图表设置弹窗

指标参数等原生图表弹窗按可见屏幕高度布局，不依赖当前图表区域高度。标题和底部操作区固定，中间参数区单独滚动；长参数表、颜色设置及底部确定按钮均可完整触达。桌面参数窗适当加宽，手机和横屏限制在可见视口内，软键盘改变可见高度时同步调整。

调整窗口尺寸时保留当前未确认的输入；本次只修改布局，沿用原有指标设置及本地／JSON／GitHub存档格式。验证覆盖标题与按钮的滚动前后位置、桌面与手机／横屏尺寸，以及短图表下的参数滚动和确认操作。

2026-11-06弹窗修复验证：`npm run check`通过54个文件664项测试、类型检查及生产构建。新增浏览器回归先复现“确定按钮可见比例0”，修复后覆盖1138×676、390×844、320×740、844×390、220px键盘可见区域；鼠标滚动和触摸滑动均只移动参数区，标题与按钮位置保持不变，输入草稿保持且确认可关闭。Supertrend、KC／TTM Squeeze、Pivots的参数、保存恢复与存档浏览器回归也通过。实际Edge的现有PIVOTS弹窗未重载，输入保持，滚到底部及恢复顶部均已检查。

手机价格轴覆盖在图内最右侧，背景透明，刻度与价格靠右对齐，使用64px触摸区域与10px刻度文字，主图／副图提示从左侧4px开始，指标信息开关置于产品工具栏，避免覆盖K线与价格提示。自适应字体、边距和副图显示预算不写入用户指标样式；原有指标颜色、参数、可见性及高度仍完整存档。

手机主图在自动模式下允许上下滑动页面；手动价格模式下，上下滑动由图表接管、不滚动页面，拖动平移蜡烛与叠加指标，缩放比例保持不变，行为与桌面鼠标拖动一致；自动模式继续自动适配，不因主图纵向拖动切成手动。横向仍浏览K线，长按／十字线及画线手势沿用原生交互。手势跟随起始主图，取消后可立即继续操作；价格轴仍支持拖动缩放、捏合与双击恢复自动。图表外的页面和弹窗保留滚动。

桌面和手机的单个“A”价格模式开关固定在主图价格轴顶部，与 USDT 计价单位标签并排。时间轴紧贴主图下方，位于主图与第一张副图之间；没有副图时仍位于主图下方。调整整体高度、副图高度、增删指标或旋转屏幕时，时间轴随主图边界移动，副图顺序和原生拖动、缩放、十字线交互保持正常。A高亮表示自动适配，关闭表示手动模式，点击即可切换。按钮位于原生手势区域之外，主图内最右侧64px透明价格轴仍可上下拖动缩放，轴拖动会进入手动模式；主图先点按再拖动也可正常平移。按钮位置和模式仍是临时界面状态，不新增配置或存档字段。

底部状态栏固定于屏幕底部；手机从下向上依次是状态栏、底部菜单、回放控制。页面滚动、手动增高图表、切换历史／实时、开始会话、横竖屏和专注模式均保持这些入口可用。根据各栏实际高度预留图表和页面底部空间，抽屉在正常屏幕上位于回放控制之上；软键盘压缩可见空间时优先保证抽屉关闭和表单可触达。菜单、状态和控制栏跟随可见视口避让软键盘。

旧workspace.panels.replay/status布尔字段继续严格校验，显式false原样本地保存、JSON配置／全部备份和GitHub往返；新版渲染不再用它们隐藏回放和状态。未提供整个workspace时仍保留本地配置，非法字段仍在写入任何数据前拒绝。其他三块面板和各尺寸存档语义不变，无新键、字段或版本；旧布局恢复后按现有提示刷新。
