# 工作区使用说明

## 桌面

图表占据主要空间，右侧用于下单，底部集中管理持仓、成交、复盘统计和账户流水。账户摘要的“详情”查看完整账户。每张仓位卡片明确标示多仓或空仓，“止盈止损”“减仓 / 平仓”“详情”只操作对应方向。多空可以同时存在，同方向加仓合并，保护价随该方向仓位保存；结束该仓位后保护价随之移除。

创建会话前可直接“创建回放”，或先打开“回放设置”调整资金、杠杆、结束时间及高级费用参数；已有会话的重置、结束、跳转结束收在回放设置内。时间跳转使用“时间定位”，不常用表单不再常驻图表周围。

“工作区”统一管理账户摘要、下单、持仓与复盘、回放控制、底部状态五个开关。各面板标题处使用展开／收起箭头，并通过aria-expanded标明当前状态。收起后正文保留在DOM中，原位留下带名称的展开条；右侧下单区保留32px展开窄轨。可直接反复切换，无需另开设置找回。专注看图时连同折叠入口一起收起，退出后恢复原状。“显示全部面板”恢复开关，“恢复默认布局”同时恢复自动图表高度及默认持仓面板高度。“专注看图”是临时模式，退出后回到已有偏好。

## 手机与横屏

宽度小于768px的手机，以及宽度小于1024px且高度不超过520px的横屏，使用固定底部导航。点击“下单”或“持仓”打开抽屉；再次点击当前“下单”或“持仓”底栏按钮即可收起，再点即可展开；点击“看图”、抽屉外遮罩、面板标题箭头或Escape也可返回图表。抽屉与桌面使用同一组件，跨尺寸切换保留下单草稿与图表实例。底部“更多”打开工作区，即使附加面板全部隐藏也能恢复。

手机默认收起行情与指标信息文字、绘图侧栏，减少文字遮挡K线，图表上的信息按钮和原生绘图入口可随时展开。输入字号至少16px，主要触摸控件约44px；表单弹窗和抽屉跟随可见视口高度，编辑时可滚动。每个编辑弹窗都有关闭按钮；键盘Tab在弹窗内循环，Escape关闭并返回触发入口。高图表允许页面滚动，同时保留顶部和底部导航。

实时模式保留相同图表工作区，右侧或底部“行情状态”查看连接信息，不提供真实交易。

## 调整图表和指标尺寸

顶部“图表尺寸”提供图表区域及现有副图的滑杆。整体高度可设280–1600px；桌面、手机独立保存；选择“自动适配”则填充当前可用空间。图表底边也可拖动，用键盘方向键每次调整20px，Shift配合方向键调整100px，Home/End设置范围端点。桌面底部持仓区域可以拖动边界或在工作区设置160–480px高度。

指标副图期望高度可设60–600px，也可以拖动原生分隔线调整。当前空间放不下全部副图时，显示尺寸按比例压缩，主图保留约180px；增高图表或回到桌面后恢复期望高度。压缩是临时显示行为，不进入备份；显式拖动会更新保存的期望高度。

## 配置与兼容

工作区配置统一保存于`workspace.layout.v1`，存档字段为`BackupPreferences.workspace`，包含五个面板开关、桌面/手机图表高度和持仓面板高度。副图高度继续使用现有`chartIndicators`配置。应用配置导出、完整导出、JSON导入及GitHub“应用配置”上传/恢复均包含这些设置。

旧存档没有`workspace`时保留本地布局。显式`false`会收起面板正文并保留原位展开入口，显式`null`会恢复自动高度，不会被当作字段缺失。非法布局在写入任何数据之前拒绝。恢复配置后按界面提示刷新，避免旧组件状态覆盖刚恢复的配置。

临时展开的抽屉、编辑弹窗、专注状态以及手机行情文字的展开状态不进入存档。Token、请求冷却和跨页面保护等设备状态不进入布局备份。

## 开发与回归

`npm run check`执行类型检查、单元测试和生产构建。浏览器回归使用模拟行情及GitHub拦截，不发送真实订单或真实云端写入：

```sh
npx playwright test e2e/app-shell.spec.ts e2e/history-storage.spec.ts e2e/workspace-keyboard.spec.ts
```

覆盖隐藏与恢复、桌面／手机独立高度、双仓保护价与减仓、标签和弹窗、触摸、横竖屏、原生指标参数／绘制、JSON与云端往返，以及可见视口因软键盘缩小时的操作可达性。手机使用Chromium触摸模拟；键盘用例保留布局视口，模拟原生visualViewport缩小事件。

`patches/klinecharts+9.8.12.patch`保留现有价格轴与手势修复，并修复同一动画帧内普通绘图抢先排队时，后续尺寸更新回调被丢弃的问题，防止切换面板后底图位图尺寸滞后。`canvas-resize.test.ts`直接验证安装包的调度代码在两种像素观察器路径下应用最新尺寸，且每帧仍只绘制一次。修改依赖补丁后，开发服务器需用`--force`重新优化依赖缓存。
